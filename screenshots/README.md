# Captures du portfolio

Captures produites depuis le site en exécution locale avec Chromium. Elles montrent les pages et modes réellement contrôlés.

- `01-home.png` — accueil en français, thème clair
- `00-home-hero.png` — aperçu du premier écran
- `02-madastore-case.png` — étude de cas complète
- `03-admin.png` — éditeur local du contenu
- `04-home-en.png` — accueil en anglais
- `05-home-dark.png` — thème sombre
- `06-home-mobile.png` — accueil, largeur 390 px
- `07-case-mobile.png` — étude de cas, largeur 390 px

Pour les recréer après démarrage du serveur Vite : `..\\.venv\\Scripts\\python.exe scripts\\capture_portfolio.py` depuis ce dossier, si Playwright et Chromium sont présents.
