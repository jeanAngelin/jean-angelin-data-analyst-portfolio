# Mise à jour locale du portfolio

L’éditeur `/admin` permet de préparer les textes et d’exporter une copie JSON. La sauvegarde dans le navigateur est limitée à cet appareil et navigateur. Il n’y a ni compte administrateur sécurisé ni synchronisation avec une version hébergée.

Pour publier les changements, reporter l’export validé dans `src/data/content.json`, remplacer les images/documents nécessaires, exécuter les contrôles de build, puis pousser le changement vers GitHub et redéployer le site.

Ne mettez jamais un mot de passe, clé API ou CV confidentiel dans le code public. Le portfolio utilise uniquement des informations publiques choisies par son propriétaire.
